# README Audit Checklist

Evaluate the README using these eight criteria.

## 1. Project purpose

Does the README clearly explain what the program does?

## 2. Requirements

Does it state the required Python version or runtime assumptions?

## 3. Installation

Does it explain whether installation or third-party dependencies are required?

## 4. Usage

Does it provide the exact command needed to run the program?

## 5. Example

Does it include a concrete input and expected output example?

## 6. Error behavior

Does it explain what happens when the input file does not exist?

## 7. Testing

Does it document how to run the automated tests?

## 8. File structure

Does it explain the important repository files?

## Rating

For each criterion use:

- PASS
- PARTIAL
- MISSING

Then provide a short overall conclusion.
